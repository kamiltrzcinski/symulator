# Symylator

A railway signaling simulation project inspired by Ebilock/SimRail workflows.

The repository is currently in planning mode. The first documentation baseline is available in `docs/`.

## Getting started

1. Read the documentation index in `docs/README.md`.
2. Align on open technical decisions from the architecture document.
3. Break the MVP into issues and assign owners.

## Goal

Build a working networked signaling simulator with:
- signaling device states and track occupancy simulation,
- timetable execution,
- shared multi-operator sessions,
- a base for future automation and AI.
